Peuplitique — Gouvernance partagée

Peuplitique est la première plateforme citoyenne indépendante où le peuple reprend la parole publique, l’analyse collective et la décision commune.

Elle repose sur un principe simple : une gouvernance partagée permet de dépasser les modèles pyramidaux traditionnels d’un pouvoir centralisé.

Elle vise à reconstruire un espace souverain où chaque citoyen contribue, analyse, propose, corrige et décide, sans intermédiaire.

Ce collectif devient alors souverain, protégé mutuellement et structuré par des règles établies par les citoyens.

Vote Token

Le droit de vote citoyen, anonyme, égalitaire et infalsifiable

1. Principe du Vote Token

Le Vote Token est un jeton citoyen unique, anonyme, non‑monétaire et non‑transférable. Il garantit l’égalité absolue : 1 citoyen = 1 token = 1 vote.

Contrairement aux systèmes basés sur l’identité (email, téléphone, carte d’identité), le Vote Token ne demande aucune donnée personnelle. Il protège la souveraineté citoyenne et élimine toute possibilité de manipulation.

2. Caractéristiques du Token Citoyen

  • Anonyme – aucune identité n’est liée au vote.
  • Unique – un seul token par citoyen pour chaque vote.
  • Infalsifiable – impossible à copier ou dupliquer.
  • Non‑monétaire – aucune valeur financière.
  • Non‑transférable – ne peut pas être donné ou vendu.
  • Non‑stockable – il disparaît après usage.

3. Cycle de vie du Token

  1. Génération : un token unique est créé pour le citoyen.
  2. Validation : le citoyen l’utilise pour voter.
  3. Vérification : le système confirme que le token n’a pas été utilisé deux fois.
  4. Destruction : le token est supprimé après le vote.
  5. Publication : la liste des tokens utilisés est rendue publique (sans identité).

4. Transparence et Vérification

Chaque citoyen peut vérifier que son token a bien été comptabilisé, sans jamais révéler son identité. Toute la communauté peut vérifier que :

  • aucun token n’a été utilisé deux fois,
  • aucun vote n’a été ajouté, retiré ou modifié,
  • le total des votes correspond exactement au nombre de tokens utilisés.

5. Pourquoi le Token est indispensable

Le Vote Token résout les limites des systèmes actuels :

  • pas besoin d’email, de téléphone ou de compte numérique,
  • pas de collecte de données personnelles,
  • pas de dépendance aux institutions,
  • pas de risque de fraude ou de manipulation.

Il permet une démocratie réelle, accessible, transparente et souveraine.
