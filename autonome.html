Ce token est généré localement dans ton navigateur. Il n’est jamais envoyé en clair, ni stocké sur un serveur. Il sert une seule fois pour signer ton vote.

3. Transparence et vérifiabilité

Ton vote est enregistré localement dans ton navigateur sous forme de données anonymes :

  • hashToken : empreinte du token (SHA‑256)
  • signature : SHA‑256(token + choix + timestamp)
  • choix : option sélectionnée
  • timestamp : date/heure du vote

Ces données peuvent ensuite être exportées ou envoyées à une API minimale pour publication dans un registre public (JSON).
